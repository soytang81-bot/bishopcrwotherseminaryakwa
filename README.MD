BISHOP CROWTHER SEMINARY, OKA — WEBSITE PROJECT

FILES
- index.html: Home page
- about.html: About, mission, vision and values
- academics.html: Academic programmes
- admission.html: Admissions information
- gallery.html: Photo gallery
- contact.html: Contact details and demo enquiry form
- css/style.css: All website styling
- js/script.js: Mobile menu and contact form demo behaviour
- images/: Place your own school logo and approved photos here

HOW TO OPEN
1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html using Live Server, or double-click index.html to view it in a browser.
4. Keep the folders named css, js and images in the same project folder.

IMPORTANT CUSTOMIZATION
The phone number and email shown are sample placeholders. Replace them with the school's official contact details. The location text currently says Oka, Nigeria; add the full address. The gallery uses sample online photographs; replace them with school-approved images. The contact form is front-end only and needs a backend or form service to deliver messages.
